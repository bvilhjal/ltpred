ltpred

Liability-threshold genetics at pedigree and registry scale.

A from-scratch Python implementation of LT-FH, LT-FH++, ADuLT and PA-FGRS. It turns a family's case/control status and ages of onset into a continuous, GWAS-ready estimate of each person's genetic liability; separate APIs fit variance-component models from family data.

v0.3.4 NumPy + SciPy · Numba optional Python ≥3.9 MIT
Run the quickstart Read the guide View on GitHub

The whole package lives on this picture: a latent Gaussian liability ℓ per person, a diagnosis when it crosses a personalized threshold T, and the proband's posterior-mean genetic liability estimated from where relatives' liabilities must lie.

01

The method lineage it implements

ltpred is a faithful, tested port of a specific line of methods — each paper adds one thing to the liability-threshold model, and ltpred implements them on one covariance engine with two complementary back-ends.

1950–65Foundations

The liability-threshold model

A latent normal liability; a disease when it exceeds a threshold set by prevalence.

Dempster & Lerner 1950 · Falconer 1965
2020LT-FH

Family history as a phenotype

Replace the 0/1 case label with the posterior-mean genetic liability given parents' and siblings' status — designed to recover GWAS information discarded by a binary label.

Hujoel et al., Nature Genetics
2022LT-FH++

Personalized thresholds

Age of onset, sex and birth cohort each get their own threshold from population CIP curves; first-degree relatives in the method (simulation panels used 0–2 siblings); a scalable Gibbs sampler. ltpred's arbitrary-pedigree path extends beyond the 2022 publication.

Pedersen et al., AJHG
2023ADuLT

Age-dependent threshold

The same personalized threshold, benchmarked as robust under the ascertainment mechanisms studied, as an alternative to time-to-event (Cox) GWAS.

Pedersen et al., Nature Communications
2024PA-FGRS

Deterministic, registry-scale

A sequential Pearson–Aitken moment approximation with lifetime-threshold case intervals and an age-censored-control mixture — no MCMC, at biobank scale.

Dybdahl Krebs et al., AJHG
02

What the package does

The supported surface is deliberately small: a lean estimation core, benchmarked and covered by the compatibility policy. Heavier prototypes — the MCEM likelihood fit, genetic-correlation and common-factor models, the sex-limited and genetic-nurture covariances, the register pipeline — live in an unsupported research/ package that ships with the repository but is not installed with the distribution. A capability rejoins ltpred proper only once it is wired into the core estimation path and benchmarked.

Estimate

Posterior genetic liability

The core score. One entry point covers both regimes: deterministic Pearson–Aitken by default for a single trait, and the truncated-MVN Gibbs sampler once a correlation matrix makes the request multi-trait — PA is single-trait only. The array fast paths, which take already-aligned bounds instead of Family objects, are imported from ltpred.estimate.

Fit

Variance components & factors

Estimate h² and shared-environment components (A + sibship C + couple M) by multiple Haseman–Elston, with family-cluster bootstrap intervals under their sampling assumptions. Both core fitters require independent, non-overlapping families and an explicit contract: sampling="population" for an unascertained cohort, or sampling="ipw" with known, strictly positive family-level inclusion probabilities. The role-wise case-rate screen can falsify a grossly inconsistent sample or weight set; passing it does not certify joint-pattern positivity. Fitted C/M feed back into single-trait role/object and array predictors via the c2/m2 arguments; the high-level multi-trait route rejects them until a cross-trait component covariance is defined. The MCEM likelihood fit, genetic-correlation and common-factor fits, and parametric-bootstrap tests live in the unsupported research/ package (research.advanced_fitting).

Scale

Biobank-ready performance

Numba-JIT, prange-parallel kernels; families grouped by structure; streaming batch-means standard errors at O(F) memory; optional float32 bounds. gibbs_estimate_batched is imported from ltpred.gibbs. At four threads the ordinary PA engine ran ~57k–78k families/second on the object path, which includes bounds assembly and grouping; the array path reached 1.2–3.8 M families/s on already-aligned, repeatedly reused inputs — a hot-kernel rate, not end-to-end preparation.

Validate

Twenty-seven reproducible benchmarks

The simulation suite covers PA accuracy and speed, calibration, genomic control, scaling, power, model-fitting recovery, CIP estimation, pedigree inference and the end-to-end register pipeline. The PA-FGRS censoring mixture has a generative validation too: three of ten paired correlation-shift confidence intervals exclude zero, but the largest shift is only −0.00034 (95% CI ± 0.00011) — statistically detectable and practically negligible at these settings. Case encoding dominates calibration there. Runs go through a provenance wrapper that records the commit, tracked-diff hash and output hashes to a manifest.

03

One idea underneath it all

The estimate is the mean of the family's liability distribution, restricted to the box the observations imply — and because it's Gaussian, it factors cleanly into a genetics part and a data part.

ĝ0 = w⊤μ,   w = V−1c,   μ = E[ ℓF | ℓi ∈ (ai, bi) ]
w — BLUP weights

Selection-index weights from heritability and kinship. They are threshold-free and determine how each observation contributes. With observed liabilities it reduces to the classical selection-index / BLUP conditional mean.

μ — truncated means

What each relative's liability averages, given status and age. Thresholds — prevalence, age of onset, sex and birth cohort — act here; these means also affect score ordering.

In the benchmarked, correctly specified simulations, personalizing thresholds by cohort and sex removed the error caused by a deliberately misspecified common threshold and sometimes improved score correlation and GWAS power. This is an empirical result, not a guarantee against other model misspecification or confounding.

Every observation is a statement about where latent liability lies. LT-FH++ and ADuLT pin an age-of-onset case at its onset threshold. Base PA-FGRS instead places an observed case above the lifetime threshold and represents a censored control as a control/future-case mixture; ltpred also exposes a separate age-specific interval-case variant. Age, sex and cohort affect thresholds or mixture weights, never the covariance.

Each modeling choice, measured

Adjusted causal-SNP power (χ² noncentrality) relative to the plain case/control label, in the integrated LT-FH++ GWAS.

10 paired replicates · 4,000 ascertained probands · age/sex/cohort CIP. These are four analysis configurations, not single-variable ablations: ADuLT→LT-FH changes both relatives and thresholds. The matched family-history contrast is ADuLT→full LT-FH++, where proband bounds are identical. Metric: causal-SNP noncentrality ratio, not the squared-correlation effective-N proxy.

Score correlation was robust; scale was not

Feed the estimator the wrong heritability: its calibration slope swings, but its correlation with the true liability barely moves.

Five 3,000-family cohorts per cell (across-seed means) · K=0.05 · true h²=0.5. In this setting, changing h² acted approximately like a linear rescaling, to which a standardized linear GWAS is insensitive. Linear GWAS uses phenotype values, not ranks alone; other nonlinear changes can alter results.

05

Where it's going

The estimation and fitting cores are in place and tested. What's next splits into closing loops that already have the machinery, deepening the model, and reaching production scale.

Close the loop

Near-term
shipped
Feed fitted C / M back into prediction. Single-trait role/object and array estimators accept fitted shared- and couple-environment components through c2= / m2=. Multi-trait use awaits an explicit cross-trait component covariance and is rejected rather than ignored.
shipped
A λGC / false-positive panel. bench_confounding pairs a secular prevalence trend with birth-cohort-correlated null SNPs: cohort-blind (single-K) thresholds inflate genomic control up to ~16× (worse than raw case/control) while cohort-aware LT-FH++ holds λGC ≈ 1 — the confounding side of the cohort story.
shipped
Competing-risk CIP helpers. ltpred.cip estimates the curve thresholds_from_cip consumes straight from follow-up records (entry age, exit age, event code): kaplan_meier_cip (left-truncated product-limit, Greenwood SEs) when there are no competing events, and aalen_johansen_cip (delayed entry, right censoring, death and emigration as competing events — the LT-FH++ construction) with the closed-form Aalen variance. In bench_cip_estimation, treating death as ordinary censoring overestimates incidence by up to 0.022 at a 42% death share, the bias Aalen–Johansen exists to avoid.
shipped
Calibration diagnostics. bench_calibration reports calibration slope / intercept and decile calibration alongside correlation. In the tested model, a wrong assumed h² primarily tilted the scale while score correlation changed little; this is not guaranteed under other misspecification.

Deepen the model

Medium-term
partly done
Relationship-specific environments. A + sibship C + couple M ship today; additional symmetric PSD sharing kernels, such as carefully defined maternal-lineage rearing or cousin environments, are candidates for extended registry pedigrees.
partly done
Sex- and cohort-specific covariance. The sex half exists as research code: construct_covmat_sex_limited (in research/covariance_extensions.py) moves sex out of the threshold and into Σ — sex-specific h² and a cross-sex genetic correlation rg — so an opposite-sex relative can carry different weight, not just a different threshold. Since the BLUP weights are threshold-free, this is what turns sex into a ranking lever rather than only a calibration correction. It reduces bitwise to the scalar model at equal h² and rg = 1, and is positive semi-definite for any |rg| ≤ 1. The parameters are supplied rather than fitted, and it feeds the covariance-level APIs; the role-based estimate_liability still takes a scalar h². Birth cohort in Σ is still to come.
partly done
Direct vs. indirect (genetic-nurture) effects. construct_covmat_nurture (in research/covariance_extensions.py) builds the covariance from the path model rather than from kinship, so a parent's genotype can shape the child's environment: parent–offspring covariance becomes h²/2 + n·h² and sib–sib h²/2 + 2n·h² + 2n²·h². They inflate by different amounts, which is what identifies the indirect path, while Cov(Ao, ℓparent) stays at h²/2 — nurture changes how a parent's liability relates to the child, not how their genotype relates to the child's own genetic value. That asymmetry is what one symmetric kinship-scaled matrix cannot express. Verified against a 4,000,000-family simulation of the path model; n = 0 reduces to the additive model exactly. fit_nurture (in research/advanced_fitting.py) then recovers both parameters in closed form: the two moments are two equations in two unknowns, so the parent–offspring/sibling ratio isolates the indirect path exactly. It also reports what a nurture-blind additive model would claim from each relative type alone — their disagreement is the diagnostic, and it is zero precisely when there is no indirect path. Nuclear families only, and on sibling covariance alone nurture is indistinguishable from a sibship C; parent–offspring covariance is what separates them.
