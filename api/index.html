    API reference¶

    A quick map of the primary workflow, followed by signatures and docstrings generated from the source for every public module (advanced array, pairwise and low-level numerical APIs included). The top-level ltpred.__all__ controls wildcard imports and is intentionally limited to the ordinary single-trait path. A wider set of names is available as explicit top-level compatibility imports; the remaining numerical functions are available from their owning modules shown below. Do not assume every generated module member is also a top-level export.

    Primary workflow¶

    Table 1. Primary workflow functions.

    function purpose
    estimate_liability end-to-end estimator (PA by default for one trait, Gibbs for multi-trait; opt-in method="quadrature" for additive nuclear families)
    fit_heritability fit liability-scale h² from independent, non-overlapping families with a common case/control threshold; sampling="population" (unascertained, screened for gross marginal case-rate inconsistency but not certified) or sampling="ipw" with weights = 1 / P(family sampled) for a known, strictly positive selected design
    prevalence_thresholds / age_thresholds classic or personalised pinned bounds; family rows determine LT-FH++ vs ADuLT
    pa_thresholds age-specific interval-case and PA-FGRS censored-control-mixture inputs; an age-dependent variant, not base PA-FGRS, exact PA-FGRS_ADT, or a requirement merely to use the PA engine
    thresholds_from_cip bounds from an empirical (population) CIP curve — case_mode="interval" is LTFHPlus's default case interval and, with the mixture, a PA-FGRS-style variant (not PA-FGRS_ADT); endpoint values are held constant outside its age grid
    families_from_columns build family inputs from flat columns
    kinship_from_pedigree / estimate_liability_from_kinship arbitrary-pedigree input and PA-default estimation; caller-supplied c_kernel/m_kernel support environmental components, and use_mixture=True with K_i/K_pop enables the PA-FGRS censored-control mixture
    estimate_liabilities supported population-trio driver: pedigree discovery, pinned-onset empirical-CIP bounds, explicit GWAS versus prospective-prediction observation sets, and calendar-time censoring
    simulate_under_LTM_single simulate role-grammar families for one trait, for testing/benchmarking
    simulate_pedigree / pedigree_birth_times simulate a population trio table (ids, father, mother) and give it generation-coherent calendar birth times
    simulate_register_liabilities simulate one consistent liability field over a pedigree and return the register columns plus the true genetic liability, so a score can be checked against truth
    simulate_followup_records simulate registry follow-up (entry age, exit age, event code) from a known incidence curve, with optional competing mortality and delayed entry — the input to kaplan_meier_cip / aalen_johansen_cip
    simulate_under_LTM_multi simulate families with two traits under A/C/M/E components, for fit_pairwise_multi
    observed_to_liability_h2 / liability_to_observed_h2 observed ↔ liability-scale h² (Lee et al.)
    set_num_threads set the Numba-parallel thread count

    Unsupported multi-trait, onset-decay, factor and nurture prototypes remain in the checkout-only research package. Gibbs seeds are uint32 integers or None; bootstrap resampling follows NumPy's default_rng contract. PA accepts PSD covariance with positive marginal variances; Gibbs requires strict PD. Array tuple contracts are PA (est, var), Gibbs (est, se) or (est, se, var), and kinship (est, se, var).

    Estimation — ltpred.estimate¶

    ltpred.estimate ¶

    Posterior genetic and full liability from family truncation bounds.

    estimate_liability handles Family objects, the array functions handle one role set per call, and estimate_liability_from_kinship handles arbitrary pedigrees. Single-trait inference defaults to deterministic Pearson--Aitken (PA); multi-trait inference uses Gibbs; additive nuclear families can use quadrature. PA alone implements the K_i/K_pop censoring mixture.

    Families are validated and grouped by role set before calling the shared kernels. var is posterior variance; se is Monte-Carlo error only. See docs/estimation.md and docs/algorithm.md for the models and fold-order details.

    LiabilityResult dataclass ¶

    Bases: _TableExport

    Aligned liability estimates and numerical diagnostics.

    est, se and var map output names to per-family arrays. var is posterior uncertainty, whereas se is Monte-Carlo error in est (zero for deterministic engines, not proof of exactness). Multi-trait names are suffixed by phenotype. pids contains proband ids, falling back to fam_id only for wholly pid-free families. Quadrature diagnostics record refinement change and nodes per active dimension, not an error bound.

    genetic property ¶
    genetic

    Return the single-trait est['genetic'] array.

    to_dict ¶
    to_dict()

    Return copied columns, including requested numerical diagnostics.

    estimate_liability_pa_arrays ¶

    estimate_liability_pa_arrays(roles, lower, upper, h2, out='genetic', K_i=None, K_pop=None, use_mixture=False, c2=None, m2=None)

    PA inference for same-structure bound arrays.

    lower and upper have shape (n_families, len(roles)); g is added internally. Returns (est, posterior_var). out selects "genetic" or "full". C/M components and the PA-only K_i/ K_pop mixture are optional. Float32 bounds halve input storage while accumulators remain float64.

    estimate_liability_gibbs_arrays ¶

    estimate_liability_gibbs_arrays(roles, lower, upper, h2, out='genetic', tol=0.01, n_sim=100000, burn_in=1000, seed=None, max_rounds=100, c2=None, m2=None, return_var=False)

    Gibbs inference for same-structure bound arrays.

    Inputs match estimate_liability_pa_arrays. Returns (est, se), plus posterior variance when return_var=True. Fresh chains of n_sim retained draws (after burn_in) are pooled until the batch-means SE is at most tol or max_rounds is reached; exhaustion warns. Seeds are uint32 integers or None and depend on global row index, making chunking and thread scheduling irrelevant.

    estimate_liability_from_kinship ¶

    estimate_liability_from_kinship(A, lower, upper, h2, target=0, out='genetic', tol=0.01, n_sim=100000, burn_in=1000, seed=None, max_rounds=100, method=None, K_i=None, K_pop=None, use_mixture=False, *, c2=None, c_kernel=None, m2=None, m_kernel=None, _certified_psd=None)

    Estimate a target's liability from an arbitrary relationship matrix.

    A is an n × n additive relationship matrix shared by all rows of lower/upper, whose shapes are (n_families, n) (one family for 1-D input). target selects the proband; their genetic coordinate is added internally. Inbred liabilities are standardised to unit marginal variance. Returns (est, se, posterior_var).

    PA is the default; Gibbs is optional. out selects genetic or full liability. The PA-only censoring mixture uses aligned K_i/K_pop. C/M proportions require aligned PSD, unit-diagonal c_kernel/ m_kernel matrices because relatedness alone cannot identify those environmental relationships.

    _certified_psd is internal: pipeline callers use its private sentinels to skip redundant matrix validation only when construction guarantees the required PSD/PD properties.

    estimate_liability ¶

    estimate_liability(families, h2, *, method=None, out=('genetic',), tol=0.01, use_mixture=False, genetic_corrmat=None, full_corrmat=None, phen_names=None, n_sim=100000, burn_in=1000, seed=None, max_rounds=100, dtype=np.float64, c2=None, m2=None, quadrature_atol=1e-08, quadrature_max_nodes=128)

    Estimate conditional genetic or full liabilities for Family objects.

    h2 is required liability-scale heritability. A scalar selects the single-trait model and deterministic PA by default; a vector with genetic_corrmat and full_corrmat selects multi-trait Gibbs. method can force "pa", "gibbs" or nuclear-family "quadrature". The PA-only censoring mixture needs use_mixture=True and member K_i/K_pop values.

    out accepts "genetic", "full" or both; multi-trait columns are suffixed by phen_names. Single-trait C/M components use c2/m2 with h2 + c2 + m2 <= 1. Float32 bounds halve storage without reducing accumulator precision.

    Gibbs controls are tol, n_sim, burn_in, seed and max_rounds. Deterministic engines warn if those controls are changed. Quadrature supports only additive, noninbred nuclear families with 0 <= h2 < 1 and no C/M or mixture; its two controls limit refinement change and nodes per dimension. Results contain summaries, not draws; use ltpred.gibbs.rtmvnorm_gibbs for draws. See docs/estimation.md for observation models, examples and uncertainty semantics.

    Nuclear-family quadrature — ltpred.quadrature¶

    This explicit array API returns QuadratureResult, not LiabilityResult. Its error is a successive-refinement diagnostic, not a certified error bound or Monte-Carlo SE; nonconvergence raises. The high-level estimate_liability(..., method="quadrature") route instead includes quadrature_error and quadrature_nodes dictionaries in LiabilityResult; its zero se means no Monte-Carlo noise. See the worked example and model scope.

    ltpred.quadrature ¶

    Posterior quadrature for additive, noninbred nuclear families.

    Conditional on the two parental breeding values, observed liabilities are independent, so siblings add likelihood factors rather than dimensions. Exact pins are conditioned first; zero/one remaining intervals use analytic moments. Otherwise a rank-1/2 factor projection, Newton mode search and mode-centred Gauss--Hermite integration compute the posterior mean and variance.

    Grid sizes double from 16 to max_nodes. Acceptance requires the last two mean/variance changes to meet atol; failure raises. Identical bound rows are solved once. The model excludes C/M, mixtures, other pedigrees and h2 = 1. See Algorithm Q in docs/algorithm.md.

    QuadratureResult dataclass ¶

    Bases: _TableExport

    Per-family posterior est and var, and numerical diagnostics.

    error is the largest change in either moment across the last two quadrature refinements. It is not a certified error bound or Monte-Carlo standard error. n_nodes is the final number of nodes per active factor dimension (zero for analytic answers), not the total tensor-grid size.

    se property ¶
    se

    Zero Monte-Carlo error; numerical refinement is reported in error.

    to_dict ¶
    to_dict()

    Copy est, se, var, error and n_nodes in input-row order (no ids supplied).

    estimate_liability_quadrature_arrays ¶

    estimate_liability_quadrature_arrays(roles, lower, upper, h2, *, out='genetic', atol=1e-08, max_nodes=128)

    Compute posterior moments for aligned nuclear-family bound arrays.

    roles contains unique o, m, f and/or numbered full sibs; bounds have shape (n_families, len(roles)). The target is the proband's genetic or full liability selected by out. Parents are unrelated and noninbred, with 0 <= h2 < 1; C/M and mixtures are unsupported.

    atol applies to the last two refinement changes, not a certified error bound. max_nodes is 64–512 per active dimension. Nonconvergence raises RuntimeError with the family index. Identical rows share one solve.

    Chunked array drivers — ltpred.chunked¶

    ltpred.chunked ¶

    Chunked and streaming wrappers for the array liability kernels.

    *_chunked slices in-memory bound arrays; *_batches consumes iterators of (lower, upper) or (lower, upper, K_i, K_pop) blocks (mappings also work). Outputs concatenate in input order and retain only O(F) summaries. PA is unchanged up to rounding. Gibbs seeds by global row offset, so results are bit-identical to the unchunked call for any partition.

    PA over slices of one role set; returns (est, var).

    Inputs match estimate_liability_pa_arrays. Full-array validation runs once before evaluating chunks of chunk_size. Use the batch API to avoid holding all bounds in memory.

    Items are 2-tuples or mappings; K columns are rejected because Gibbs has no censoring mixture. Any partition is bit-identical to one array call at the same seed.

    Liability-scale transformations — ltpred.liability_scale¶

    ltpred.liability_scale ¶

    Observed/liability heritability and probit variance transformations.

    The Lee factor converts observed case/control heritability to liability scale using population prevalence K and, for ascertained studies, sample case fraction P. The inverse transformation divides by the same factor.

    For SNP effect beta and allele frequency f, probit residual-scale variance is q = 2 f (1-f) beta^2; its single-predictor fraction of total latent variance is q/(1+q). GWAS z-based variance subtracts one unit of null noise by default.

    observed_to_liability_h2 ¶

    observed_to_liability_h2(obs_h2, pop_prev, prop_cases=None)

    Observed-scale h² -> liability scale (Lee et al. 2011).

    Multiplies obs_h2 by K(1-K)/z² with z = phi(Phi^-1(1-K)), plus the ascertainment factor K(1-K)/(P(1-P)) when the study over-samples cases. pop_prev is the population prevalence K and prop_cases the sample case fraction P (None for an unascertained sample, which drops the ascertainment factor); both must be finite and lie in (0, 1), or ValueError is raised. Vectorised over the inputs.

    liability_to_observed_h2 ¶

    liability_to_observed_h2(liab_h2, pop_prev, prop_cases=None)

    Liability-scale h² -> observed scale (Lee et al. 2011).

    The inverse of observed_to_liability_h2: divides liab_h2 by the same factor, with pop_prev (K) and prop_cases (P, or None) under the same rules.

    probit_liability_r2 ¶

    probit_liability_r2(beta, maf, *, fraction=False)

    Return probit residual-scale variance 2 f (1-f) beta².

    With fraction=True, return the single-predictor fraction q/(1+q). Sum residual-scale variances across independent SNPs before applying that nonlinear transformation, not the fractions themselves.

    liability_r2_from_z ¶

    liability_r2_from_z(z, n, pop_prev, prop_cases=None, *, subtract_null=True)

    Estimate small-effect liability variance from GWAS z statistics.

    Returns ((z² - 1) / n) * c by default, where c is the same Lee factor used by observed_to_liability_h2; subtract_null=False omits the unit null term. Estimates can be negative per SNP and assume a calibrated null. Sum only independent or LD-pruned signals, or use an LD-aware aggregate.

    Tetrachoric correlation — ltpred.tetrachoric¶

    ltpred.tetrachoric is the function; import these names from ltpred or with from ltpred.tetrachoric import ....

    ltpred.tetrachoric ¶

    Tetrachoric maximum-likelihood correlation for binary pairs.

    Marginal case proportions set the thresholds. With those margins fixed, the saturated 2x2 model gives a unique root p_both(rho) = a/n, solved by Brent's method using the pairwise fitters' Plackett probabilities. The reported Wald SE comes from observed information conditional on the thresholds. Pairwise estimates need not form a PSD matrix.

    TetrachoricResult dataclass ¶

    One tetrachoric estimate.

    rho the MLE; se the observed-information standard error, conditional on the estimated marginal thresholds and Wald-shaped, so it is optimistic near the |rho| -> 1 boundary and in small samples; thresholds the two marginal thresholds; n the observed pair count (the raw table total, never inflated by the continuity correction); corrected whether the 0.5 continuity correction was applied to a zero cell.

    tetrachoric_table ¶

    tetrachoric_table(a, b, c, d, *, continuity_correction=True)

    Tetrachoric MLE from a 2x2 table of counts.

    The table reads a = both cases, b = first case only, c = second case only, d = neither. Cell counts must be finite, nonnegative integers; fractional or non-finite counts are rejected. A zero cell gets a 0.5 continuity correction added to all four cells when continuity_correction (the standard handling; the estimate is then boundary-avoiding rather than exactly +/-1); with continuity_correction=False a zero cell raises. Monomorphic margins (one variable all-one-level) are rejected: there is no correlation information. se is NaN when the numeric curvature at the optimum is not positive.

    tetrachoric ¶

    tetrachoric(x, y, *, continuity_correction=True)

    Tetrachoric MLE between two binary arrays of equal length.

    x and y are 1-D boolean or 0/1 arrays (NaN or other codes raise), one entry per pair. They are tabulated with x as the first variable, so x-only cases form cell b, and fitted by tetrachoric_table, which sets the zero-cell handling (continuity_correction) and rejects a monomorphic array.

    tetrachoric_matrix ¶

    tetrachoric_matrix(X, *, continuity_correction=True, check_psd=True)

    Return pairwise tetrachoric correlations among columns of binary X.

    Each pair uses tetrachoric_table. Independent estimates need not be PSD; check_psd=True warns on a materially negative eigenvalue.

    Register pipeline — ltpred.pipeline¶

    Prediction requires per-person birth_time and per-proband index_time on a common numeric calendar scale whose unit matches age; this is what gives relatives from different birth years their correct attained-age censoring landmarks. Structural ancestors in the pedigree's exact-kinship closure are not diagnosis observations unless condition_closure=True is explicitly requested. Under use="prediction" the estimand is E[g | relatives' records at the landmark] — it is not additionally conditioned on the proband being disease-free at the landmark; the two rank probands of one age and family structure almost identically but differ in level across ages, because surviving to an older age disease-free is evidence of lower liability. Accuracy and throughput evidence: RESULTS §21.

    Two boundary diagnostics are surfaced on PopulationScores rather than silently absorbed: frac_records_with_unresolved_parents (the fraction of records with a non-null parent reference matching no id — a zero resolved share raises, a share above half warns) and, under use="prediction", proband_state (disease_free_and_followed / prevalent_case / exited_before_index at the landmark, with a warning on prevalent cases).

    ltpred.pipeline ¶

    Population-register scoring from trio records and empirical CIPs.

    For each proband the driver extracts relatives plus ancestral closure, forms the GWAS or calendar-censored prediction observation set, converts records to pinned-onset CIP bounds and scores with deterministic PA. Closure-only rows are structural and uninformative unless explicitly requested.

    When a conservative eigenvalue bound proves that no PD repair is needed, unbounded rows are marginalised and the repair check is skipped. Required relationships come from a dense tabular fill or bounded selected-pair recursion; both are exact. Boundary cases retain the full pedigree and legacy repair. Outputs include observation counts and unresolved-parent diagnostics. See Algorithm R in docs/algorithm.md.

    PopulationScores dataclass ¶

    Bases: _TableExport

    Aligned register scores, posterior variances and cohort diagnostics.

    Counts distinguish structural relatives, conditioned observations and closure-only ancestors. proband_state is prediction-only and identifies prevalent cases and follow-up exits at the landmark. frac_records_with_unresolved_parents helps distinguish a register boundary from a broken parent-id join.

    se

    estimate_liabilities ¶

    estimate_liabilities(ids, father, mother, *, probands, status, age, use, cip_ages=None, cip_values=None, k_pop=None, h2, max_degree=3, birth_time=None, index_time=None, condition_closure=False, strata=None, cip_by_stratum=None, kinship_cache_size=100000)

    Score probands from population parent pointers and diagnosis records.

    status and age align to ids; age is onset for cases and last follow-up for controls. Supply liability-scale h2, unique probands, max_degree and either one (cip_ages, cip_values, k_pop) curve or strata with cip_by_stratum.

    use="gwas" includes the proband's diagnosis. use="prediction" leaves it uninformative and requires aligned birth_time plus one index_time per proband. Every relative is censored at their own age index_time - birth_time; future records become controls and people not yet born are uninformative. Ancestral closure is also uninformative unless condition_closure=True.

    kinship_cache_size bounds selected-pair reuse. Zero disables caching, warns and is usually much slower without meaningful memory savings. Unresolved-parent and prevalent-proband diagnostics are returned/warned; they do not replace cohort eligibility checks. Inference is pinned-onset LT-FH++ with PA; use lower-level APIs for other observation models.

    CIP estimation — ltpred.cip¶

    ltpred.cip ¶

    Cumulative incidence from follow-up records with delayed entry.

    kaplan_meier_cip estimates net incidence with Greenwood SEs; aalen_johansen_cip estimates cause-specific crude incidence with competing risks and finite-risk-set, tie-correct Aalen SEs. A person is at risk at t when age_entry < t <= age_exit; zero-length follow-up cannot carry an event. Both estimators handle right censoring and tied event ages.

    The returned CipCurve feeds thresholds_from_cip per population stratum. Curves reaching one cannot define a finite probit threshold; choose a justified lifetime horizon and k_pop. See docs/cip-estimation.md for estimand choice and examples.

    CipCurve dataclass ¶

    Ascending event ages, cumulative incidence, pointwise SEs and counts.

    kaplan_meier_cip ¶

    kaplan_meier_cip(age_entry, age_exit, is_event)

    Estimate net cumulative incidence 1 - S(t) by Kaplan--Meier.

    age_entry and age_exit are aligned follow-up ages; is_event is boolean or exact 0/1. Delayed entry and right censoring use the risk convention entry < t <= exit. Returns event ages, cumulative incidence and Greenwood pointwise SEs in a CipCurve.

    For the proportion actually diagnosed before death, death is a competing event rather than censoring: use aalen_johansen_cip instead.

    aalen_johansen_cip ¶

    aalen_johansen_cip(age_entry, age_exit, event_type, cause=1)

    Estimate cause-specific cumulative incidence by Aalen--Johansen.

    event_type uses 0 for censoring, cause for the event of interest and other positive codes for competing events. Follow-up arrays match kaplan_meier_cip. Returns every event age with sum S(t-) * d_cause / Y and finite-risk-set, tie-correct Aalen SEs. The variance recurrence remains defined when the final risk set is exhausted.

    Pedigree discovery — ltpred.pedigree¶

    ltpred.pedigree ¶

    Discover pedigrees from population parent-offspring records.

    build_parent_graph indexes parents, children and full-sibling edges; extract_pedigree performs a breadth-first search to max_degree and then adds every recorded ancestor needed for exact kinship. Full-sib edges make parents, children and full siblings distance one; grandparents, half-sibs and avuncular relatives distance two; first cousins distance three.

    Closure-only ancestors retain their shortest degree and are marked so their diagnoses need not enter the observation set. Output order is proband first, then (degree, str(id)), independent of record order.

    ParentGraph dataclass ¶

    Validated parent-child index of a population's trio records.

    ids are the unique person ids; sire/dam give each person's father/mother as indices into ids (or -1 for unknown/founder). children[i] lists the indices of person i's recorded children; sibs[i] the indices of person i's full siblings (two shared parents) — the sib edges that make traversal distance equal the standard relationship degree (Pedersen et al. 2025). n_unresolved_parents counts non-null father/mother values that matched no id; declared-unknown parents (None, NaN, pandas NA/NaT or empty/NA strings) are not counted. Zero/"0" is unknown only when it is not an explicitly listed person id.

    Pedigree dataclass ¶

    One proband's extracted pedigree.

    ids/father/mother feed ltpred.covariance.kinship_from_pedigree directly; a parent is None only when unrecorded, since closure includes every recorded parent. degree[i] is the relationship-degree distance of member i from the proband (0 = proband; closure ancestors carry their shortest ancestral chain distance, always above max_degree). closure_only[i] is true when the member was added only to preserve exact kinship, after the max_degree traversal; it is an explicit warning that the person's diagnosis is outside the requested observation set unless a caller deliberately opts in. Ordering is deterministic: proband first, then by (degree, str(id)).

    member_index maps each member to its index in the parent graph. sire_index/dam_index give each member's father/mother as a position in this pedigree (-1 when unrecorded), so relationships can be computed without rebuilding an id-to-index map. All three are None only for a hand-assembled Pedigree.

    build_parent_graph ¶

    build_parent_graph(ids, father, mother)

    Index population trio records for traversal.

    ids must be unique; a parent not among ids (None, nan, or any unlisted value) is an unknown founder. Unlisted non-null values are counted in n_unresolved_parents: a register boundary makes some of them inevitable, but the count is what lets a caller distinguish that boundary from an id-format mismatch or a failed join. Raises ValueError when ids/father/mother differ in length, when ids contains a missing value (None, NaN, pandas NA/NaT or a missing-marker string such as ""/"NA"), on duplicate ids and on a person recorded as their own parent. Longer cycles (a person being their own ancestor) are not checked here; ltpred.covariance.kinship_from_pedigree raises on them.

    extract_pedigree ¶

    extract_pedigree(graph, proband, max_degree=2)

    Extract one proband's relatives and complete ancestral closure.

    BFS visits relatives through max_degree; closure then adds every recorded ancestor, making extracted kinship exact even with inbreeding. closure_only identifies added ancestors. max_degree must be a positive integer and proband must be present.

    Thresholds — ltpred.thresholds¶

    ltpred.thresholds ¶

    Convert status, age and cumulative incidence into liability bounds.

    Thresholds are computed tail-safely as T = -Phi^-1(K). Cases can be pinned at their onset threshold or bounded below by it; controls lie below their follow-up-age threshold. Uninformative rows use (-inf, inf). With relatives these bounds support LT-FH/LT-FH++; without relatives, ADuLT. Optional K_i/K_pop arrays feed the PA censoring mixture.

    Every public helper whose result depends on pop_prev requires that value explicitly. There is no disease-independent prevalence default: the 0.05 and 0.10 values in examples are properties of those examples, not package constants.

    liability_threshold ¶

    liability_threshold(pop_prev)

    Single-prevalence liability threshold T = Phi^-1(1 - K).

    convert_age_to_cir ¶

    convert_age_to_cir(age, pop_prev, mid_point=60.0, slope=1.0 / 8.0)

    Cumulative incidence rate at a given age (logistic curve).

    cir(age) = pop_prev / (1 + exp((mid_point - age) * slope)) -- incidence climbs from ~0 at young ages toward pop_prev at old ages, passing half-way at mid_point. Vectorised over age.

    convert_age_to_thresh ¶

    convert_age_to_thresh(age, pop_prev, mid_point=60.0, slope=1.0 / 8.0)

    Liability threshold implied by an age (or age of onset).

    The threshold is Phi^-1(1 - cir(age)) where cir is convert_age_to_cir, so a younger onset (lower incidence) gives a higher threshold, i.e. a more extreme liability. Vectorised over age. Port of LTFHPlus::convert_age_to_thresh (the logistic branch; the truncated-normal dist="normal" alternative is not ported).

    convert_liability_to_aoo ¶

    convert_liability_to_aoo(liability, pop_prev, mid_point=60.0, slope=1.0 / 8.0)

    Age of onset implied by a case's true liability.

    Higher liability -> earlier onset: the logistic curve of convert_age_to_cir inverted at the incidence 1 - Phi(liability). Returns nan where 1 - Phi(liability) >= pop_prev (the liability never reaches the lifetime threshold, a non-case) and 0 where the implied age would be negative. Vectorised. Port of LTFHPlus::convert_liability_to_aoo (the logistic branch; the truncated-normal dist="normal" alternative is not ported).

    prevalence_thresholds ¶

    prevalence_thresholds(status, pop_prev)

    Classic LT-FH bounds from binary status and a single prevalence.

    Cases get (T, inf) and controls (-inf, T) with T = Phi^-1(1 - K). status must be a one-dimensional Boolean or exact numeric 0/1 array; missing-value and other numeric codes are rejected, and pop_prev must be a scalar in (0, 1). Returns (lower, upper) arrays -- no age information, the special case LT-FH before ++.

    age_thresholds ¶

    age_thresholds(status, age, pop_prev, mid_point=60.0, slope=1.0 / 8.0)

    Return onset-pinned case bounds and age-censored control bounds.

    age is onset for cases and last follow-up for controls. This logistic demonstration is mainly for simulation; production register analyses use thresholds_from_cip with appropriate stratum-specific curves.

    pa_thresholds ¶

    pa_thresholds(status, age, pop_prev, mid_point=60.0, slope=1.0 / 8.0)

    Return age-specific interval bounds and PA mixture inputs.

    Cases use [T(onset), inf) with NaN mixture values; controls use (-inf, T(follow-up)) plus their current and lifetime incidence. With use_mixture=True, the control's age-specific upper only flags censoring: PA splits at the lifetime threshold and does not apply age twice. Without the mixture, all supplied bounds apply directly.

    This is an age-dependent PA-FGRS-style variant, not base PA-FGRS. For the latter, use lifetime bounds from prevalence_thresholds and add control K_i/K_pop values.

    thresholds_from_cip ¶

    thresholds_from_cip(status, age, cip_ages, cip_values, k_pop=None, case_mode='pin', min_cip=1e-05)

    Build liability bounds and mixture inputs from an empirical CIP.

    CIP is linearly interpolated at each age, clipped to [min_cip, k_pop] and converted tail-safely to a threshold. Endpoint values are held constant outside the age grid. k_pop defaults to the curve maximum and should represent the intended lifetime horizon.

    case_mode="pin" fixes cases at their onset threshold; "interval" bounds them below by it. Controls always use an upper bound at their follow-up age and receive K_i/K_pop (NaN for cases). Call once per population stratum. These encodings are not base PA-FGRS, whose cases use the lifetime threshold.

    Covariance — ltpred.covariance¶

    ltpred.covariance ¶

    Liability-scale covariance from roles or arbitrary pedigrees.

    Role constructors use the LTFHPlus relationship grammar and optional sibship (C) and couple (M) kernels. The pedigree route computes A = 2 * kinship and constructs V = h2 A + c2 C + m2 M + e2 I, standardising full liabilities to unit variance before prepending the target genetic coordinate. correct_positive_definite shrinks off-diagonals when numerical repair is needed. See docs/algorithm.md for equations and model restrictions.

    Covmat dataclass ¶

    A liability-scale covariance matrix plus the role labelling of its rows.

    roles[i] is the family role of row i (g, o, m, ...). For the multi-trait case phen_names is set and rows are phenotype-major: row i belongs to phenotype phen_names[i // (d // n_pheno)] and the roles list repeats the per-trait roles once per phenotype.

    get_relatedness ¶

    get_relatedness(s1, s2, h2)

    Return shared-DNA fraction times h2 for two role labels.

    Roles cover the proband (o), genetic target (g), parents, siblings, grandparents, half-sibs, avuncular relatives and children (c<group>.<idx>). Use h2=1 for the bare fraction. Opposite-side relatives and mates are unrelated; children in one partner group are full sibs. Same-side half-sib sets use the role grammar's shared-other-parent convention; more complex pedigrees need construct_covmat_from_kinship.

    construct_covmat_single ¶

    construct_covmat_single(fam_vec=('m', 'f', 's1', 'mgm', 'mgf', 'pgm', 'pgf'), add_ind=True, *, h2, c2=None, m2=None)

    Construct a single-trait role covariance.

    Rows are g, o and the supplied relative roles when add_ind. h2 must exceed 1e-8 and be at most one. Optional C/M components alter full-liability off-diagonals only and require h2 + c2 + m2 <= 1. Returns a Covmat containing its row labels.

    construct_covmat_multi ¶

    construct_covmat_multi(fam_vec=('m', 'f', 's1', 'mgm', 'mgf', 'pgm', 'pgf'), add_ind=True, *, genetic_corrmat, full_corrmat, h2_vec, phen_names=None)

    Construct a phenotype-major multi-trait role covariance.

    Supply one heritability per trait and symmetric, unit-diagonal genetic and full-liability correlation matrices. With D = diag(sqrt(h2_vec)), both G = D @ genetic_corrmat @ D and full_corrmat - G must be PSD. Same-person cross-trait entries use genetic covariance for g and full correlation otherwise.

    kinship_from_pedigree ¶

    kinship_from_pedigree(ids, father, mother)

    Return (ids, A) where A = 2 * kinship in input-id order.

    father and mother align to unique ids. Missing or unlisted parents are founders; a zero id is a parent only when explicitly listed. The tabular recursion handles inbreeding and arbitrary depth, returning A[i,i] = 1 + F_i. Missing/duplicate ids, self-parenting and cycles raise. Feed A to construct_covmat_from_kinship.

    construct_covmat_from_kinship ¶

    construct_covmat_from_kinship(A, h2, target=0, add_ind=True, *, c2=None, c_kernel=None, m2=None, m_kernel=None, _certified_psd=None)

    Construct a standardised liability covariance from additive kinship A.

    Forms V = h2 A + c2 C + m2 M + e2 I and scales full liabilities to unit variance. With add_ind, prepends the target genetic coordinate on the same scale; rows are g, o_0, ..., o_{n-1}. Environmental kernels must be supplied explicitly, symmetric PSD with unit diagonal, because they cannot be inferred from A. Requires h2 + c2 + m2 <= 1.

    A is validated as finite, symmetric and PSD unless an internal certificate is supplied. The role grammar's same-side half-sib convention is the only standard-pedigree case where role and pedigree covariances can legitimately differ.

    correct_positive_definite ¶

    correct_positive_definite(covmat, correction_val=0.99, correction_limit=100, eps=1e-08)

    Shrink off-diagonals until the covariance is strictly positive definite.

    Each iteration multiplies off-diagonals by correction_val and preserves the diagonal. Returns (corrected_copy, n_iterations); already-PD input needs zero iterations. Raises after correction_limit unsuccessful steps. This changes the model and callers warn when it was necessary.

    Model fitting — ltpred.fit¶

    ltpred.fit ¶

    Stochastic moment fits of liability variance components.

    fit_heritability fits additive h2; fit_variance_components fits A/C/M proportions in Sigma = sum_c theta_c K_c + (1 - sum_c theta_c) I. Persistent truncated-normal chains augment liabilities, then a damped Haseman--Elston regression updates the proportions. Retained fixed-point traces provide the estimate and a batch-means Monte-Carlo diagnostic, not a sampling SE.

    Families must be independent, non-overlapping and have common case/control thresholds. Population sampling or known positive family-level IPW is required. bootstrap_fit resamples whole families for sampling uncertainty. See docs/inference.md and Algorithm H in docs/algorithm.md.

    FitResult dataclass ¶

    Heritability estimate and its fixed-point traces.

    h2_se is batch-means Monte-Carlo error in this fit, not a sampling SE or a confidence interval. samples is post-burn-in and trace full; neither is a posterior chain. Use bootstrap_fit for sampling uncertainty.

    VarCompResult dataclass ¶

    Result of fit_variance_components.

    components maps each fitted component ("A" additive, "C" sibship common environment, "M" couple/spousal environment) to its estimated proportion of the liability variance; residual is the remaining e2. So A is the (narrow-sense) heritability. se is a within-dataset Monte-Carlo diagnostic (same caveat as FitResult), not across-dataset sampling uncertainty. Use an appropriately designed family-cluster bootstrap for sampling uncertainty. traces are the post-burn-in proportion traces per component, and n_iter and burn_in the controls the fit ran with.

    BootstrapResult dataclass ¶

    Result of bootstrap_fit.

    estimate is the point estimate from the full data; se the bootstrap standard error (SD, ddof=1, of the resampled estimates); ci_low / ci_high the percentile confidence interval at ci_level; samples the (n_boot, …) array of per-resample estimates. Shapes follow whatever the estimator returns (scalar → shape (); vector/matrix → that shape).

    fit_heritability ¶

    fit_heritability(families, *, h2_init=0.5, n_iter=1500, burn_in=500, inner_sweeps=5, damp=0.2, seed=None, eps=0.0001, sampling=None, weights=None)

    Fit liability-scale heritability from common-threshold family data.

    The stochastic fixed point alternates truncated-MVN augmentation with a damped Haseman--Elston update. n_iter and burn_in count outer iterations, inner_sweeps sets Gibbs work per iteration, and damp controls the update. h2_init lies in [0, 1]; at least four retained iterates are required. Related pairs are necessary for identification.

    Families must be independent and non-overlapping. Use sampling="population" for an unascertained sample, or sampling="ipw" with one reciprocal inclusion probability per family for a known, strictly positive selection design. Omitting sampling warns and assumes population sampling. Personalised bounds, onset pins and two-sided intervals are outside this fitter's scope. The marginal case-rate screen catches gross inconsistency but does not certify the design.

    Returns a FitResult. h2_se measures Monte-Carlo noise in this fit, not sampling uncertainty; use bootstrap_fit for the latter.

    fit_variance_components ¶

    fit_variance_components(families, components=('A', 'C'), *, n_iter=1500, burn_in=500, inner_sweeps=5, damp=0.2, seed=None, eps=0.0001, sampling=None, weights=None)

    Fit A/C/M liability-variance proportions by stochastic moment regression.

    components selects additive genetic (A), full-sibship environment (C) and/or couple environment (M). Identifying relationship contrasts must be observed; dominance is unsupported. The algorithm, controls and sampling contract match fit_heritability. Component proportions sum to at most one and residual is the remainder.

    Returns a VarCompResult. Its se values are within-fit Monte-Carlo diagnostics, not sampling SEs; use family resampling for uncertainty.

    bootstrap_fit ¶

    bootstrap_fit(families, estimator, *, weights=None, n_boot=100, seed=None, ci_level=0.95)

    Estimate percentile uncertainty by resampling whole families.

    estimator receives the family list and returns a scalar or array of stable shape. With weights, it instead receives (families, weights) and both are resampled by the same indices. Fix the estimator's own seed so bootstrap spread reflects family resampling rather than sampler noise. Returns the full-data estimate, refit SD, percentile interval and samples. Independent, non-overlapping clusters and a valid sampling design remain necessary; boundary intervals are not automatically calibrated.

    Pairwise model fitting — ltpred.pairwise¶

    PairwiseFitResult reports a component covariance matrix and sampling SEs only for identifiable interior fits; boundary or insufficient-information results mark those fields NaN and provide inference_status. Thresholds and weights are treated as fixed. See pairwise fitting for the sampling contract and distinction from the existing stochastic fitters.

    ltpred.pairwise ¶

    Single-trait A/C/M fitting by binary-pair composite likelihood.

    Jointly observed relative pairs are aggregated into weighted 2x2 tables keyed by their covariance-kernel row. SLSQP maximises the bivariate-normal composite likelihood with analytic derivatives and non-negativity/residual constraints. A family-cluster sandwich estimates sampling covariance at identifiable interior optima; it is withheld at boundaries or with insufficient information.

    The input and sampling contracts match ltpred.fit. Thresholds and weights are fixed; the composite likelihood is not a full-family likelihood or a basis for ordinary likelihood-ratio tests. See Algorithm L in docs/algorithm.md.

    Component fractions, optimizer diagnostics and optional sandwich SEs.

    covariance follows component_order and se is its diagonal SD. Both are NaN at a boundary or with insufficient clusters/information; inference_status records why. composite_loglik is not a full-data likelihood and must not be used for ordinary likelihood-ratio tests.

    Gibbs sampler — ltpred.gibbs¶

    ltpred.gibbs ¶

    Truncated multivariate-normal Gibbs sampling.

    For Q = Sigma^-1, gibbs_params forms conditional means P[i,j] = -Q[i,j]/Q[j,j] and standard deviations sqrt(1/Q[j,j]). Each free coordinate is sampled from its truncated normal conditional; coordinates spanning less than 1e-8 are fixed. Strongly coupled blocks also receive joint Gaussian updates along whitened directions.

    Batched estimation integrates out each family's unbounded coordinates and streams Rao--Blackwellised sums and batch means without retaining draws. Per-family seeds make results independent of scheduling and chunking. Persistent chains used by the fitters draw uniforms from a thread-local NumPy generator. See Algorithm G in docs/algorithm.md.

    Pearson–Aitken — ltpred.pearson_aitken¶

    ltpred.pearson_aitken ¶

    Deterministic Pearson--Aitken truncated-Gaussian moments.

    Conditioning coordinate i updates the remaining means by Sigma_ji (m* - m_i) / v_i and covariances by a rank-one update. The no-mixture path marginalises absent rows, conditions pins jointly by observation mask, then folds intervals last-to-first and the target last. Pins plus at most one interval are exact; multiple intervals use a sequential two-moment approximation and can depend on fold order.

    The PA-only censoring mixture splits each eligible control at its lifetime threshold, with weights from K_i/K_pop. Stable truncated moments use log-CDF differences and local Gauss--Legendre quadrature for narrow or extreme intervals. See Algorithms P and M in docs/algorithm.md.

    pa_algorithm ¶

    pa_algorithm(covmat, lower, upper, target=0, K_i=None, K_pop=None)

    Return PA posterior mean and variance for one family.

    target selects the covariance row to estimate. Without a mixture, pins are conditioned jointly and absent non-target rows marginalised; active K_i/K_pop pairs select the censoring mixture. All-NaN pairs leave the plain path unchanged. Without a mixture, the result is exact after pins with at most one remaining interval. Singular support with dependent interval observations is rejected.

    pa_estimate_batched ¶

    pa_estimate_batched(covmat, lowers, uppers, target=0, K_is=None, K_pops=None, *, _psd_certified=None)

    Vectorised pa_algorithm over families sharing one covariance.

    lowers/uppers are (F, d) per-family bounds; covmat is shared. Reorders once so the target is row 0. Without K_is/K_pops it runs Algorithm P, sharing the pin reduction by observation mask and never allocating the (F, d) mixture arrays. With arrays, only families with active pairs use Algorithm M; all-NaN families still use Algorithm P. Returns the PA sequential-moment approximations (est, var) of length F.

    Simulation — ltpred.simulate¶

    ltpred.simulate ¶

    Liability-threshold simulations with retained generating truth.

    Role-family draws use a canonical Cholesky factor for reproducibility across LAPACK builds. Age-aware simulations distinguish threshold-crossing, stochastic and liability-dependent onset from the bounds written for cases.     Output of simulate_followup_records.

    age_entry/age_exit/event are the three columns ltpred.cip.aalen_johansen_cip and ltpred.cip.kaplan_meier_cip consume, with event coded 0 = administratively censored, 1 = diagnosed, 2 = died. onset and death_age are the underlying latent times (inf when the event never happens), kept so an estimate can be checked against the generating curve. n_dropped counts records removed because age_exit <= age_entry.

    MultiTraitSimulation dataclass ¶

    Output of simulate_under_LTM_multi.

    liabilities is (n_families, d, n_traits) with roles ordering the d people; status is the (n_families * d, n_traits) person-major boolean case matrix the bounds were built from; families is the list to pass to ltpred.pairwise_multi.fit_pairwise_multi. phen_names and pop_prev give each trait's name and prevalence; covmat is the (n_traits * d, n_traits * d) generating covariance, trait-major (row p * d + j is person j, trait p). truth echoes the generating variance parameters, so a fit can be scored against them.

    simulate_under_LTM_single(fam_vec=('m', 'f', 's1', 'mgm', 'mgf', 'pgm', 'pgf'), add_ind=True, h2=0.5, n_sim=1000, pop_prev=0.1, use_age=False, mid_point=60.0, slope=1.0 / 8.0, seed=None, onset_model=None, case_encoding=None, onset_resolution=1.0, onset_rho=None)

    Simulate single-trait role families and their observed bounds.

    n_sim counts families. h2 and pop_prev are the generating values; seed follows NumPy's default_rng. Without ages, all members use classic LT-FH bounds. With use_age=True, current ages are generation-consistent and onset can be threshold-crossing, stochastic or liability-dependent (Gaussian copula strength onset_rho).

    case_encoding selects onset pins, age-specific intervals or lifetime intervals. onset_resolution is the register's recording grid (one year by default, or exact onset with None).     pedigree_birth_times ¶

    pedigree_birth_times(ids, father, mother, *, base_birth_year=1920.0, generation_years=30.0)

    Assign generation-coherent calendar birth times to a pedigree.

    Co-parents are placed in the same generation (a union-find over couples) and every child at least one generation later than its recorded parents -- exactly one unless a mating skips generations, as with an uncle and his niece, where the uncle moves down to his partner's generation -- so birth times are base_birth_year + generation_years * generation. Use this to obtain the birth_time column ltpred.pipeline.estimate_liabilities needs for use="prediction" calendar-time censoring when the pedigree itself carries no dates. (phensim.pedigree_birth_times gives the same years on simulated pedigrees but refuses generation-skipping matings, so this permissive placement for real pedigrees stays here.)

    Raises ValueError on invalid parent records or a generational cycle, including a parent and child constrained to the same co-parent generation. Unlike simulate_pedigree, this consumes no randomness and is deterministic for a given pedigree.

    simulate_register_liabilities ¶

    simulate_register_liabilities(rng, ids, father, mother, *, h2, cip_ages, cip_values, eval_age, method='dense')

    Simulate one coherent pedigree liability field and register records.

    Draws G ~ N(0, h2 A) once for the population plus independent residuals, then standardises genetic and full liabilities by each person's raw full-liability SD. Shared relatives therefore have one status and one genetic value across all probands.

    Onset is the supplied CIP's threshold crossing; observed status is onset by finite, nonnegative eval_age and age is onset for cases, eval_age otherwise. CIP ages must be finite, nonnegative and strictly increasing; probabilities must lie in [0, 1) and strictly increase to a positive value. method="dense" factors dense A; "mendelian" uses phensim's exact linear-storage recursion. They agree in distribution, not draw-for-draw. Returns register columns, true genetic values and residual variances.

    Joint pairwise fitting — ltpred.pairwise_multi¶

    ltpred.pairwise_multi ¶

    Joint binary-trait covariance fitting by pairwise composite likelihood.

    The trait-major model is Sigma = G ⊗ A + S ⊗ C + T ⊗ M + E ⊗ I with PSD components and unit total variance per trait. Jointly observed coordinate pairs are tabulated by trait pair and kernel row, then fitted with analytic scores under component and correlation constraints. A projected-score check certifies stationarity.

    Family-cluster sandwiches and delta methods provide h2/rg/re/rp SEs at identifiable interior fits; all are withheld at a covariance boundary. Missingness must preserve pair distributions. Thresholds and weights are fixed.

    MultiTraitPairwiseResult dataclass ¶

    Joint A/C/M/E matrices and sampling diagnostics.

    parameter_covariance follows parameter_order; se contains delta-method h2/rg/re/rp SEs, withheld at any boundary. re standardises residual E only, while rp sums all components. Zero-variance component correlations are NaN. composite_loglik is not a full-data likelihood.

    fit_pairwise_multi ¶

    fit_pairwise_multi(families, *, components=('A',), sampling=None, weights=None, phen_names=None, eps=1e-06, maxiter=300, tol=1e-10)

    Fit joint heritabilities and genetic/residual trait correlations.

    Each member needs one bound per trait and a common threshold per trait; uninformative traits contribute no pairs. components contains A and optional C/M. Component matrices are PSD with unit total variance and residual eigenvalues at least eps. phen_names labels the traits.

    The independent-family and population/IPW contracts match fit_pairwise. maxiter and tol control SLSQP and stationarity checks. Interior fits return family-cluster/delta-method SEs; any covariance boundary withholds them. Composite likelihood does not support ordinary likelihood-ratio tests.
